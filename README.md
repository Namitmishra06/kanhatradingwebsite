Kanha Trading – Industrial Hardware Website

📖 Overview

Kanha Trading is a responsive business website developed using HTML, CSS, and JavaScript. The website represents an industrial hardware supplier by showcasing its products, company information, inquiry form, and contact details through a clean and modern user interface.

---

✨ Features

- Responsive Design
- Modern UI/UX
- Navigation Bar
- Hero Section
- About Us Section
- Product Showcase
- Inquiry Form
- Contact Section
- Google Maps Integration
- WhatsApp & Call Buttons
- Testimonials
- FAQ Section
- Smooth Animations

---

🛠 Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Tabler Icons

🚀 How to Run

1. Download or clone the repository.
2. Keep all project files in the same folder.
3. Open index.html in any modern web browser.
4. No installation or server is required.
